# Heart Disease Prediction Dashboard using SVM

## Overview

Machine Learning project that predicts heart disease risk using Support Vector Machine (SVM).

## Features

- Data preprocessing
- Feature scaling
- SVM classification
- ROC Curve
- Confusion Matrix
- Streamlit Dashboard

## Installation

```bash
pip install -r requirements.txt
```

## Train Model

```bash
python src/train.py
```

## Evaluate Model

```bash
python src/evaluate.py
```

## Run Dashboard

```bash
streamlit run app.py
```
